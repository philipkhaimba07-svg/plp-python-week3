# Grade Reporter & Bug Hunt

- grade_reporter.py: gives each score a grade and prints the pass count, fail count and average.
- bug_hunt.py: a fixed program that adds the numbers 1 to 5 and prints 15.

The hardest bug to find was the loop condition count < 5, because Python showed no error message. I knew something was wrong because the program printed 10, and I know 1 + 2 + 3 + 4 + 5 is 15.
